# Changelog

All notable changes to this site are documented here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-10-08

### Changed
- Hero disc on desktop is 50% larger and centred behind the head, so it backs the hair and chin.
- Hero portrait is clipped to the disc's curve below its centre line, hiding the photo's straight crop edges. The clip follows the disc's scroll parallax.
- Mobile hero portrait is larger so its crop edge falls outside the disc.

### Fixed
- Portrait cutout is fully opaque with a clean anti-aliased edge, removing the faded blazer and the dark halo around the silhouette.
- Hero image alt text now describes the current photo.

## [1.0.0]

- Baseline: the site as it stood before versioning began.
